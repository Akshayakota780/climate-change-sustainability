# climate-change-sustainability
Climate change impact on agricultural land sustainability using machine learning
Project Overview

This project studies the impact of climate change on agricultural land sustainability using Machine Learning techniques.

Objectives

- Understand how climate change affects agricultural land.
- Collect and preprocess relevant climate and agricultural data.
- Explore Machine Learning models for data analysis.
- Support better understanding of sustainable agriculture.

Technologies Used

- Python
- Django
- SQL
- Machine Learning
- Support Vector Machine (SVM)
- Random Forest

Data Preprocessing

- Load the dataset using Pandas.
- Remove duplicate records.
- Handle missing values.
- Prepare data for analysis.

Project Status

Project documentation and implementation are in progress.
